# Honda Motos Chile — recreación visual

Proyecto **Next.js + TypeScript + Tailwind** que replica la estética de [motos.honda.cl](https://motos.honda.cl/): header con menú off-canvas, slider, catálogo por categoría, ficha de modelo y CTAs laterales en rojo Honda.

No es el sitio oficial. Las imágenes de producto se cargan desde el CDN público de Honda Chile.

## Cómo correrlo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).
